# Agent 决策机制：反应型 vs 规划型

## 🎯 核心对比

| 维度 | ⚡ 反应型 (Reactive) | 🧩 规划型 (Planning) |
|------|---------------------|---------------------|
| **逻辑** | 感知 → 触发（刺激-响应） | 目标 → 拆解 → 执行 |
| **记忆** | ❌ 无记忆、无规划 | ✅ 有全局视角 |
| **速度** | ⚡ 快（直接响应） | ⏱️ 较慢（需生成计划） |
| **复杂度** | 简单独立任务 | 复杂多步骤任务 |
| **一致性** | 局部最优 | 全局最优 |
| **容错** | 弱（仅重试当前动作） | 强（可回滚/调整） |
| **实现** | 低复杂度 | 高复杂度（需状态管理） |

---

## 💡 适用场景

### ⚡ 反应型
- ✅ 问答机器人
- ✅ 简单FAQ回复
- ✅ 单API查询

### 🧩 规划型
- ✅ 旅行规划（航班+酒店+租车）
- ✅ 数据分析流水线
- ✅ 多步骤文档处理

---

## 📝 场景演示

**任务**："我想去上海旅行"

### ⚡ 反应型 Agent
```
直接回复：
"上海有很多景点，如外滩、迪士尼..."
```

### 🧩 规划型 Agent
```
生成计划：
1️⃣ 查询上海天气
2️⃣ 推荐景点
3️⃣ 查找机票
4️⃣ 推荐酒店
→ 按顺序执行
```

---

## 🔑 核心洞察

> **选择原则**：
> - 任务简单、要求快速 → 反应型
> - 任务复杂、需协调 → 规划型
> - 实际系统常采用**混合型**：底层反应 + 上层规划
