# Agent Skills 到底是个啥

Agent Skill最近真是太火了，那它到底是个啥？厉害在哪里？

## 本套课程目标

本套课程，我们做三件事：

1. **理解Skill** — 搞清楚 Agent Skill 的结构和原理
2. **定制Skill** — 从易到难，能自己定制 Skill
3. **推荐Skill** — 分享好用的、必用的 Skill

## 什么是 Skill？

我们通过简单的提示词，例如：帮我做一张iwen餐厅的「慧灵顿牛排仅需38元，先到先得」的促销海报，他就会按照品牌、风格、定位、目标客群等维度生成符合我们需求的海报。

我们还推荐了一些好用的、必用的Skill，例如做前端页面的 `frontend-design`，做PPT的 `pptx`，做文档处理的 `docx`，做表格处理的 `xlsx` 等等。

课程中所有的配套资料都为大家准备好了，包含软件、文档、资料包等，私信或者评论区留言获取！希望各位给个点赞、收藏、关注！

## Skill 的类比理解

Skill 翻译过来就是「技能」，这和每个人对应每个职业，都会对应职业的专业技能是一样的。例如，你是一名程序员，你就会理解需求、编写代码、调试Bug等技能。

每个技能都有对应的规范，你有编写代码技能，在编码的过程中，你要有开发流程、参考文档、开发工具、静态资源。

在 Agent Skill 的术语里面，对应关系如下：

| 职业技能 | Agent Skill |
|---------|-------------|
| 开发流程 | `SKILL.md` |
| 参考文档 | `references/` |
| 开发工具 | `scripts/` |
| 静态资源 | `assets/` |

> 核心设计理念：**渐进式披露（Progressive Disclosure）**。启动时只加载 `name` + `description`（约 100 token），匹配到任务后才加载 `SKILL.md` 全文，需要时再进一步读取 `references/`、`scripts/` 等。这意味着装几十个 Skill 也不会消耗额外 token。

## Skill 目录结构

我们将上面的内容打包成一个文件夹，它就是一个技能：

```
~/Skill/              # 技能目录
├── SKILL.md          # 核心说明文件（必填）
├── references/       # 附加参考文档
├── scripts/          # 可执行脚本
└── assets/           # 静态资源（图片等）
```

## Skill 案例：iwen-creative

```yaml
---
name: iwen-creative
description: 为iwen餐厅生成符合品牌调性的物料设计创意，当用户说要做某种物料(海报、易拉宝、工服、包装盒等)，你需要输出这个物料的设计创意。
---
```

```markdown
# iwen-creative — 为iwen餐厅生成符合品牌视觉规范的各类营销物料，输出创意方案

## 品牌核心元素
- 品牌名: iwen餐厅
- 风格: 年轻、潮流、有网感
- IP形象: 布偶猫
- 主色: 薄荷绿 #5DDEB5
- Slogan: A FRESH, MODERN BITE / 健康轻食主义
- 风格: 3D 卡通、清新时尚、年轻活力

## 你的任务
当用户说要做某种物料(海报、易拉宝、包装盒等)，你需要输出符合iwen餐厅品牌风格的物料的设计创意。

## 输出格式
请按以下格式输出:

### 创意主题
(一句话概括这个设计的核心概念)

### 视觉风格
(整体氛围、配色方向、质感)

### 画面构成
(主体元素、背景、装饰元素的布局描述)

### 细节建议
(一些能让设计更出彩的小细节)
```
