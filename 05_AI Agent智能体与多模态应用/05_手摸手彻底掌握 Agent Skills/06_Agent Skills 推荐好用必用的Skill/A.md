# 推荐好用必用的 Skill

大部分的 Skill 其实是不需要我们自己创建的，有很多现成好用的 Skill。

## 必用 Skill 清单

| Skill | 用途 |
|-------|------|
| `pptx` | 生成和编辑 PowerPoint 演示文稿 |
| `docx` | 生成和编辑 Word 文档 |
| `xlsx` | 生成和处理 Excel 表格 |
| `pdf` | PDF 文档读取、生成与表单填写 |
| `imagen` | AI 图片生成 |
| `frontend-design` | 前端页面设计与组件生成 |
| `skill-creator` | 自动将工作流转化为 Skill |

## Anthropic 官方推荐的 9 大 Skill 类别

来自 Anthropic 2026 年官方博客总结的内部分类：

1. **库与 API 参考** — 内部/第三方库的正确用法、常见踩坑
2. **产品验证** — 自动化测试、浏览器驱动验证（Playwright + tmux）
3. **数据获取与分析** — 对接监控、数据仓库、BI 工具
4. **业务流程自动化** — 将重复工作流变成一键命令
5. **代码审查** — 安全审查、代码质量检查
6. **代码生成** — 特定框架/模式下的代码脚手架
7. **文档生成** — API 文档、变更日志、README
8. **运维部署** — CI/CD、容器化、基础设施即代码
9. **安全合规** — 安全扫描、许可证检查
