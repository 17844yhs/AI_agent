# MCP 通信机制对比

## 三种主要机制

| 协议方式 | 底层机制 | 流式支持 | 长连接 | 适用场景 |
|---------|---------|---------|--------|---------|
| **Stdio** | stdin/stdout | ✅ | ✅ | 本地开发、插件集成 |
| **SSE** | HTTP + EventStream | ✅ | ✅ | 在线对话、流式输出 |
| **HTTP** | HTTP 请求-响应 | ❌ | ❌ | 简单 API 调用 |

---

## 一、Stdio（标准输入输出）

**特点**：不依赖网络，本地直连，快速安全

**适用场景**：
- 本地 IDE 插件（VS Code、IntelliJ）
- 本地调试

---

## 二、SSE（Server-Sent Events）

**特点**：HTTP 长连接，支持流式输出，自动重连

**适用场景**：
- 聊天对话（像 ChatGPT 边生成边显示）
- 长任务执行（实时返回进度）

---

## 三、HTTP 模式

**特点**：标准请求-响应，简单兼容

**适用场景**：
- 一次性任务（REST API 调用）
- 简单远程服务集成

---

## 选择建议

```
本地开发调试     → stdio
在线流式对话     → SSE
简单远程调用     → HTTP
```

> **总结**：本地用 stdio，在线用 SSE，简单用 HTTP。
