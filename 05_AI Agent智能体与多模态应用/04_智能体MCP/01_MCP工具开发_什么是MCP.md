# MCP（Model Context Protocol）是什么

## 核心定义

**MCP** 是一个开放标准协议，让 AI 模型能够统一连接外部数据源、工具和服务。

**类比**：MCP 就像 AI 的"USB-C 接口"——一个标准接口，所有工具都能插上。

---

## 解决的核心问题

| 问题 | MCP 的解决方案 |
|------|---------------|
| **物理隔离** | AI 无法访问本地文件、数据库 | 提供统一的工具调用协议 |
| **协议碎片化** | 每个工具都要单独集成 | 一次开发，到处可用 |
| **时效性缺失** | AI 无法获取实时数据 | 支持实时数据访问 |
| **安全隐患** | 缺乏统一的授权机制 | 内置 OAuth 和安全控制 |

## 核心架构

```
┌─────────────────────────────────────────────────────────┐
│                        Host                              │
│                  (Claude, ChatGPT, Cursor)                │
└────────────────────┬────────────────────────────────────┘
                     │
        ┌────────────┼────────────┐
        │            │            │
   ┌────▼────┐  ┌───▼────┐  ┌───▼────┐
   │ Client  │  │ Client │  │ Client │
   └────┬────┘  └───┬────┘  └───┬────┘
        │            │            │
   ┌────▼────┐  ┌───▼────┐  ┌───▼────┐
   │ Server  │  │ Server │  │ Server │
   │(GitHub) │  │(Notion)│  │(Stripe)│
   └─────────┘  └────────┘  └─────────┘
```

### 三层组件

| 组件 | 作用 |
|------|------|
| **Hosts** | AI 应用（Claude Desktop、Cursor 等） |
| **Clients** | 每个服务器一个客户端，独立连接 |
| **Servers** | 暴露工具、资源、提示词的服务 |

---

## MCP 服务器能力

| 能力 | 说明 | 示例 |
|------|------|------|
| **Tools** | 可调用的函数 | 发送邮件、查询数据库 |
| **Resources** | 可读的数据源 | 文件内容、配置信息 |
| **Prompts** | 预定义的提示模板 | 代码审查模板、翻译模板 |
| **Tasks** | 长时间运行的操作 | 批量处理、复杂工作流 |

---

## 2025 年周年更新特性

| 特性 | 说明 |
|------|------|
| **Task-based Workflows** | 支持长时间运行操作，状态管理 |
| **简化授权** | URL-based 注册、安全凭证收集 |
| **企业安全** | PCI 合规支付处理、企业 IdP 控制 |

---

## 生态系统

- **知名 MCP 服务器**：Notion、Stripe、GitHub、Hugging Face、Postman
- **治理**：Linux Foundation 的 Agentic AI Foundation

---

## 关键要点

> **一句话总结**：MCP 是 AI 的通用接口标准，让一次开发的工具可以在所有 AI 平台使用。
