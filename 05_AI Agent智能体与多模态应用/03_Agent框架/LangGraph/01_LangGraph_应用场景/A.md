# 🎯 LangGraph 的作用

## 📊 LCEL vs LangGraph 对比

| 特性 | LCEL | LangGraph |
|------|------|-----------|
| **适用场景** | 简单流程 | 复杂流程 |
| **执行方式** | ✅ 线性执行 | ✅ 循环控制 |
| **代码复杂度** | ✅ 代码简洁 | ⚠️ 需要定义图结构 |
| **步骤类型** | ✅ 固定步骤 | ✅ 条件分支 |
| **状态管理** | ❌ 无 | ✅ 内置状态管理 |
| **人工介入** | ❌ 不支持 | ✅ 支持中断/恢复 |
| **持久化** | ❌ 无 | ✅ 检查点机制 |
| **可视化** | ❌ 无 | ✅ 图形化展示 |

---

## 💡 核心区别

### 🔹 LCEL：线性流水线
```
输入 → 处理1 → 处理2 → 输出
```
- 适合：简单的 ETL、问答链
- 优势：快速开发、易理解

### 🔸 LangGraph：有向图
```
     ↗ 分支A ↘
输入 → 决策节点 → 输出
     ↘ 分支B ↗
     (可循环)
```
- 适合：Agent、多轮对话、工作流
- 优势：灵活控制、状态追踪

---

## 🚀 何时选择？

**选 LCEL**：
- 流程固定且简单
- 不需要循环或复杂分支
- 追求开发速度

**选 LangGraph**：
- 需要循环迭代（如自我修正）
- 需要条件分支（如路由）
- 需要人工审核/介入
- 需要保存和恢复状态
