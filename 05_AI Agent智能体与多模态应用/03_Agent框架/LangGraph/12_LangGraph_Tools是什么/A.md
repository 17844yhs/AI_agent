# 🎯 学习目标

- 理解 **Tool Calling** 的工作原理：LLM 决定调用哪个工具
- 掌握 LangChain 中工具的定义方式
- 了解工具的三大要素：**名称**、**描述**、**参数**

---

## 💡 核心概念

**Tool Calling（工具调用）**：LLM 不直接执行工具，而是输出"调用指令"（工具名 + 参数），由外部代码执行后把结果返回给 LLM。

---

## 🔄 工作流程

```
用户提问 → LLM 分析 → 决定调用工具 → 生成 tool_calls
                                    ↓
                              外部代码执行工具
                                    ↓
                              返回结果给 LLM
                                    ↓
                              LLM 整合结果 → 回答用户
```

---

## 🍽️ 生活化比喻：餐厅点菜

| 角色 | 对应组件 | 职责 |
|------|---------|------|
| **顾客** | 用户 | 提出需求 |
| **服务员** | LLM | 不直接做菜，但知道厨房有什么菜、每道菜需要什么配料 |
| **厨房** | Tool | 实际执行做菜的操作 |

### 📋 完整流程

```
顾客点菜 → 服务员写菜单（tool_calls）→ 交给厨房执行 → 把菜端回来 → 服务员告诉顾客
```

## 🔧 工具的三大要素

```python
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """搜索互联网信息"""  # ← 描述（LLM根据描述决定是否调用）
    return f"搜索结果..."  # ← 执行逻辑

# search.name        → "search"              ← 名称（LLM用名称指定调用哪个工具）
# search.description → "搜索互联网信息"       ← 描述（LLM用描述理解工具用途）
# search.args_schema → {"query": str}        ← 参数（LLM自动提取参数值）
```

### 📊 三要素详解

| 要素 | 属性 | 作用 | 示例 |
|------|------|------|------|
| **名称** | `name` | LLM 用名称指定调用哪个工具 | `"search"` |
| **描述** | `description` | LLM 用描述理解工具用途 | `"搜索互联网信息"` |
| **参数** | `args_schema` | LLM 自动提取参数值 | `{"query": str}` |

---

## 🎯 关键点总结

- ✅ **LLM 不执行工具**：只生成调用指令（tool_calls）
- ✅ **外部代码执行**：解析指令，调用实际工具，返回结果
- ✅ **三大要素缺一不可**：
  - 名称 → 识别工具
  - 描述 → 理解用途
  - 参数 → 传递数据
- ✅ **描述很重要**：LLM 根据描述决定是否调用工具
