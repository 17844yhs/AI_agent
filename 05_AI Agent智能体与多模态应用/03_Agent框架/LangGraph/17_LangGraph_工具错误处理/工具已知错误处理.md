# 🎯 学习目标

- 理解**已知错误**的特点和处理方式
- 掌握在工具内使用 `try-except` 捕获异常
- 学会返回友好的中文错误提示

---

## 📖 介绍

**已知错误**是指可以预见的错误，如参数不合法、格式错误等。对于这类错误，应该在工具内部用 `try-except` 捕获，直接返回友好的错误信息。

---

## 💡 适用场景

| 错误类型 | 示例 | 处理方式 |
|---------|------|---------|
| **除零错误** | `100/0` | 捕获 `ZeroDivisionError` |
| **语法错误** | `2++3` | 捕获 `SyntaxError` |
| **参数错误** | 缺少必填字段 | 手动验证参数 |
| **安全限制** | 包含危险操作 | 检查并拒绝执行 |

## 💻 代码示例：计算器工具

```python
import os
from dotenv import load_dotenv
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI
from langgraph.prebuilt import create_agent

load_dotenv()

llm = ChatOpenAI(
    base_url=os.getenv("OPENAI_API_BASE"),
    api_key=os.getenv("OPENAI_API_KEY")
)

# 工具内部 try-except 处理已知错误
@tool
def calculate(expression: str) -> str:
    """计算数学表达式，输入数学表达式字符串。"""
    try:
        # 安全检查：防止恶意代码执行
        if any(op in expression for op in ["import", "open", "exec", "__"]):
            return "错误：表达式包含不安全的操作"
        
        result = eval(expression)
        return f"计算结果：{result}"
    
    except SyntaxError:
        return "错误：表达式格式不正确，请检查括号和运算符"
    
    except ZeroDivisionError:
        return "错误：除数不能为零"
    
    except Exception as e:
        return f"计算错误：{type(e).__name__} - {e}"

# 创建 Agent
app = create_agent(llm, [calculate])

# 测试：正常、格式错误、除零错误
tests = [
    "帮我计算 (25+15)*3-10",
    "帮我计算 100/(5-5)",    # 除零
    "帮我计算 2++3",         # 语法错误
]

for question in tests:
    result = app.invoke({"messages": question})
    print(f"用户：{question}")
    print(f"AI：{result['messages'][-1].content}\n")
```

### 📊 运行结果

```
用户：帮我计算 (25+15)*3-10
AI：(25+15)*3-10 = 80，计算结果是80。

用户：帮我计算 100/(5-5)
AI：错误：除数不能为零。100除以(5-5)的除数为0，无法计算。

用户：帮我计算 2++3
AI：错误：表达式格式不正确，请检查括号和运算符。"2++3"不是有效的数学表达式。
```

## 🔑 关键要点

### ✅ 优点

1. **用户体验好**：返回友好的中文提示
2. **Agent 不会崩溃**：错误在工具内部被处理
3. **安全性高**：可以阻止危险操作执行
4. **可控性强**：完全自定义错误消息

### ⚠️ 注意事项

```python
# ✅ 正确：捕获具体异常类型
except ZeroDivisionError:
    return "错误：除数不能为零"

# ❌ 错误：捕获所有异常（会掩盖未知错误）
except Exception:
    return "出错了"
```

## 🎯 最佳实践

### 1️⃣ 安全检查优先

```python
@tool
def execute_code(code: str) -> str:
    """执行代码。"""
    # 先做安全检查
    dangerous_keywords = ["import os", "subprocess", "eval(", "exec("]
    if any(keyword in code for keyword in dangerous_keywords):
        return "错误：不允许执行危险操作"
    
    # 再执行业务逻辑
    try:
        result = eval(code)
        return f"结果：{result}"
    except Exception as e:
        return f"执行错误：{e}"
```

### 2️⃣ 参数验证

```python
@tool
def search_products(keyword: str, min_price: float, max_price: float) -> str:
    """搜索商品。"""
    # 参数验证
    if min_price < 0 or max_price < 0:
        return "错误：价格不能为负数"
    
    if min_price > max_price:
        return "错误：最低价格不能高于最高价格"
    
    # 正常业务逻辑
    return f"搜索'{keyword}'，价格{min_price}-{max_price}..."
```

### 3️⃣ 分层异常处理

```python
@tool
def process_data(data: dict) -> str:
    """处理数据。"""
    try:
        # 第一层：参数验证
        if "name" not in data:
            return "错误：缺少必填字段 'name'"
        
        # 第二层：业务逻辑
        result = complex_processing(data)
        
        # 第三层：结果验证
        if not result:
            return "错误：处理结果为空"
        
        return f"处理成功：{result}"
    
    except ValueError as e:
        return f"参数错误：{e}"
    
    except KeyError as e:
        return f"字段缺失：{e}"
    
    except Exception as e:
        return f"未知错误：{type(e).__name__}"
```
