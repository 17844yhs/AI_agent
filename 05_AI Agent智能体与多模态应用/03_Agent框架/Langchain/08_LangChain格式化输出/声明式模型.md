# 声明式模型

## 学习目标
- 理解声明式模型在大语言模型输出控制中的核心思想
- 使用 Pydantic 模型和 `with_structured_output()` 构建可靠、类型安全的 LLM 应用

## 1. Pydantic + Structured Output
从 LangChain v0.3 开始，其内部已完全支持并升级到 Pydantic v2。这意味着框架原生就能高效处理 Pydantic 模型。

AI 应用要落地，首要挑战是保证输出结果稳定可靠。手动解析字符串容易出错，而 Pydantic 模型提供的强类型验证，能极大提高数据输出的准确性和一致性。

LangChain 提供的 API（如模型的 `.with_structured_output()` 方法），让绑定 Pydantic 模型变得异常简单，代码更清晰。

## 2. 主要优势
- 强类型验证：自动检查输出字段类型和约束
- 结构稳定：避免模型输出格式漂移
- 可读性强：业务逻辑与输出结构一目了然
- 易调试：解析失败时能快速定位问题

## 3. 适用场景
- 结构化数据提取（如 JSON、表格、配置项）
- QA 结果规范化
- 表单自动填充
- 企业级接口调用结果输出控制
