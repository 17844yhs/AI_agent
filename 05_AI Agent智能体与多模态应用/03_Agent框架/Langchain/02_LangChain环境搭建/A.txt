1.学习目标
    了解如何配置Langchain环境搭建
    了解接入(通义)模型的流程

2.环境配置
创建虚拟环境
    conda create -n agent_env python=3.12
# 或者
    uv venv -p 3.12
    uv init

3.安装Langchain包
    pip install langchain-community==0.4.1
    pip install dashscope==1.25.9

4.注册API的Key
    不同的运营商，有不同的注册方式
    大模型服务平台百炼控制台：https://bailian.console.aliyun.com/#/home
    创建Key: https://bailian.console.aliyun.com/?tab=model#/api-key
